Práctica: Clasificación Zero-shot

Author

Guillermo Ruiz

  1. Descomprime el archivo datos-3A.zip que contiene:

    • un directorio de imágenes
    • el archivo miml_labels_1.csv con las etiquetas de las imágenes

  2. Carga el modelo CLIP usando la instrucción:

    model,_,preprocess= open_clip.create_model_and_transforms('ViT-B-32',
pretrained='laion2b_s34b_b79k')

  3. Usa el modelo para clasificar las imágenes en las categorías:

    categorias = ["an image of a desert", 
              "an image of a mountain", 
              "an image of a sea", 
              "an image of a sunset"]

  4. Para cada imagen, obtener su encaje y compararlo con los encajes de las categorías y asignarle la más similar.

Nota: Para que sea más rápido el cálculo de los embeddings, activa el entorno de ejecución con una GPU/TPU en colab.

  1. Imprime las imágenes (en tamaño 100x100) en donde la clasificación no coincida con la clase verdadera según el archivo miml_labels_1.csv. Incluye la clase predicha por el CLIP y la real.

  2. Imprime la clasificación según el modelo de las siguientes imágenes: [‘13.jpg’, ‘405.jpg’, ‘417.jpg’, ‘836.jpg’, ‘1216.jpg’]

  3. Escribe una conclusión de la eficacia del modelo en la clasificación.

  4. Contesta la evaluación de esta práctica en el Aula Virtual.
